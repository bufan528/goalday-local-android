# Reference APK

This directory contains the reference APK used for reverse-engineering and UX replication of the original Goalday-style app.

Files:

- `goalday-reference-base.apk`

Purpose:

- provide a stable local reference artifact for UI/UX comparison
- allow contributors to extract assets, inspect manifests, and compare interaction flows
- keep the replica effort aligned with the original APK behavior and visual structure

Notes:

- this APK is included for local reverse-engineering and reference use inside this repository
- do not treat it as source code
- extracted outputs should be kept in separate analysis folders if contributors unpack it
